# Telegram Bot for 3MF Converter

Бот для конвертации .3mf файлов из Bambu Lab в Snapmaker U1 с расчетом стоимости печати.

## Возможности

- 📤 **Конвертация файлов**: Загрузка и конвертация .3mf файлов прямо в Telegram
- 💰 **Расчет стоимости**: Автоматический расчет стоимости печати на основе:
  - Веса материала
  - Типа филамента (PLA, PETG, ABS, TPU)
  - Времени печати
  - Наличия поддержек
- 📱 **Mini App**: Полноценный веб-интерфейс внутри Telegram
- 🔧 **Настройка филаментов**: Выбор и настройка цветов и типов материалов

## Установка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` или установите переменные окружения:

```bash
TELEGRAM_BOT_TOKEN=your_bot_token_here
WEB_APP_URL=https://your-domain.com
API_HOST=0.0.0.0
API_PORT=8080
```

### 3. Получение токена бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Создайте нового бота командой `/newbot`
3. Скопируйте полученный токен

### 4. Настройка Mini App (опционально)

1. В @BotFather используйте команду `/newapp`
2. Укажите URL вашего веб-сервера (например, `https://your-domain.com`)
3. Привяжите Mini App к кнопке меню

## Запуск

```bash
cd telegram_bot
python bot.py
```

Или с использованием переменных окружения:

```bash
TELEGRAM_BOT_TOKEN=your_token python bot.py
```

## Использование

### Команды бота

- `/start` - Запустить бота и показать главное меню
- `/convert` - Начать процесс конвертации файла
- `/calc` - Калькулятор стоимости
- `/help` - Справка по использованию

### Через Mini App

1. Нажмите кнопку "📱 Mini App" в меню бота
2. Загрузите .3mf файл
3. Просмотрите анализ и стоимость
4. Нажмите "Конвертировать и скачать"

## Конфигурация цен

В файле `bot.py` можно настроить параметры расчета стоимости:

```python
PRICING_CONFIG = {
    "base_price": 5.0,        # Базовая стоимость заказа ($)
    "price_per_gram": 0.05,   # Цена за грамм филамента
    "price_per_hour": 2.0,    # Цена за час печати
    "support_multiplier": 1.2,# Множитель при наличии поддержек
    "material_prices": {      # Цена за грамм по типам
        "PLA": 0.03,
        "PETG": 0.04,
        "ABS": 0.05,
        "TPU": 0.06,
    }
}
```

## Технические детали

- Файлы автоматически удаляются через 8 часов
- Максимальный размер файла: 200MB
- Поддерживается до 4 филаментов (аппаратное ограничение U1)
- Конвертация сохраняет цвета и настройки модели

## Требования

- Python 3.9+
- aiogram 3.x
- aiohttp 3.9+
- Pillow 10+
